# tools/ — how the animated assets are made

Every SVG in `assets/brand/` that moves is generated by a script here. None of
them are hand-edited; CI regenerates all of them and fails if the committed file
differs, so editing an SVG directly would be reverted by the next run.

```bash
python3 tools/gen_phases.py     # then commit the result
```

| Script | Produces | Notes |
|---|---|---|
| `gen_phases.py` | `phases-{light,dark}.svg` | **Reads the Status table in `docs/ROADMAP.md`.** Run it after changing a phase's state. |
| `gen_hero.py` | `hero-{light,dark}.svg` | README hero — the system self-test. |
| `gen_system.py` | `system-{light,dark}.svg` | The three-box architecture diagram. |
| `gen_conops.py` | `conops-{light,dark}.svg` | Mission 2 end to end. |
| `gen_patrol.py` | `patrol-{light,dark}.svg` | Waypoint patrol with the obstacle deviation. |
| `gen_mesh.py` | `mesh-{light,dark}.svg` | The 915 MHz message net. |
| `gen_avoid.py` | `avoid-{light,dark}.svg` | Forward obstacle avoidance (Phase 6, not built). |
| `gen_cta.py` | `cta-{light,dark}.svg` | The *System overview* button. |

Only `gen_phases.py` reads anything outside itself. The rest are self-contained,
so their output changes only when the script does.

They are stdlib-only, like `tests/`, so they run on a laptop, the Jetson or CI
without installing anything.
